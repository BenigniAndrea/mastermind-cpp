Mastermind in C++
Simulazione in linguaggio C++ del classico gioco di logica e deduzione Mastermind. Il software ha due modalità di gioco:
1.il computer genera un codice segreto basato su una sequenza di numeri e guida l'utente attraverso una serie di tentativi, fornendo un feedback matematico preciso per ogni mossa.
2.l'utente sceglie la sequenza di numeri e guida il computer attraverso una serie di tentativi, fornendo un feedback matematico preciso per ogni mossa.

Tecnologie Utilizzate
C++ Libreria Standard C++
Funzionalità Principali
Generazione Randomica: Creazione di un codice segreto tramite funzioni di randomizzazione con seed temporale.
Validazione Input: Controllo rigoroso degli input dell'utente per evitare crash o inserimenti non validi.
Logica di Feedback: Calcolo accurato delle "O" (numero corretto, posizione errata) e "X" (numero e posizione corretti) tramite iterazioni sugli array.
Obiettivo Formativo:
Il progetto, sviluppato durante gli studi superiori, mi ha permesso di consolidare le conoscenze sui costrutti iterativi, sull'allocazione della memoria statica e sulla gestione degli array mono e bidimensionali in C++.
